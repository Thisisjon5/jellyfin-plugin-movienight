# Roadmap — from proven v3 to usable (ruled by Jon, 2026-08-16)

Context: the v0.3.28 switcher-v3 acceptance test PASSED (see ITERATION-LOG
arc 6) — universal pause/resume works across Web + Roku. This roadmap is the
agreed path from "proven in a test rig" to "usable for a real movie night."
Jon's ruling 2026-08-16: all four steps, in this order.

## 1. Rewire config page to v3 — `building`

The dashboard config page's Go Live / Pause-Resume / Stop buttons and status
readout drive the v3 pipeline (`sw2/*` endpoints) instead of the old HLS
path. Item-ID paste box stays for now.

**Done when:** a full golive → pause → resume → stop cycle runs entirely
from the dashboard page (phone browser counts), no curl involved.

## 2. Movie-length soak — `blocked on 1`

Jon hosts a real movie night through that page: full-length feature, a few
pauses spread across it, Web + Roku.

**Done when:** movie completes end-to-end with pause/resume cycles, sessions
survive throughout, logs clean, no orphan processes.

Rides along: Roku periodic-stutter investigation (arc 6 open finding b) —
diagnose from FFmpeg.Remux/DirectStream logs, don't guess. Slate warm-start
polish (finding a) slots here or in step 3, whichever the soak shows is
needed.

## 3. Promote v3 + delete HLS machinery — `blocked on 2, GATED on Jon's ruling`

The real "Movie Night" channel and official `/MovieNight/api/*` endpoints
become the v3 pipeline; spike naming goes away; the HLS writer,
filler/resume/splice code, and segment-serving routes get deleted from
BroadcastManager. Big deletion — own session.

**Done when:** plain channel broadcasts via v3, dead code gone, regression
pass (golive/pause/resume/stop + tune on Web + Roku) passes.

**Hard gate:** Jon rules on the deletion commit before it happens.

## 4. Proper UI — `blocked on 3 for build; mocks may start anytime`

Movie picker instead of item-ID paste, host controls designed for real use,
possibly a host surface outside the admin dashboard. Mocks first — no UI
code before Jon approves a direction.

**Done when:** Jon has approved a mock and the built version matches it,
running against the promoted v3 API.
